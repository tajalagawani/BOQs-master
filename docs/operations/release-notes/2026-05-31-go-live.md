### Infrastructure stood up

- Azure VM `iox-vm-01` in UAE North (Standard_D2s_v3)
- PostgreSQL 16 with 17 Prisma tables + 48 Drizzle `px_*` tables (65 total)
- nginx reverse proxy on :80 → Next.js :3000
- pm2 process manager (iox-web + iox-worker)
- GitHub Actions CI/CD pipeline (push to main → live in ~3 min)
- All 7 Azure resources tagged `app=IOX-OS`

- 14 BOQ runs (mix of statuses)
- 140 activity log entries

- **ProcureX integrated** (OmniApp full port) as the 4th IOX module
